# Backend

This directory is for the PlanMy backend services and API.

The project is currently in the planning and prototyping phase. Setup and run instructions will be added when the backend implementation is in place.

#### update 13.11.2026
- Currently one can find 2 different backend skeletons: the adonisJS and the nodeJS expressJS ones.   The migration to the first one is taking place to handle the authentication and other services with AdonisJS's libraries. 

- Adonis is connected to the local pg database, can handle calls relative to the user
