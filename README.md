# PlanMy 🎉

PlanMy is a university project aiming to simplify event planning. Users will be able to create events, discover service providers, and manage their bookings in one place.

## Planned Features
- Create and manage events
- Explore service providers
- View provider details and pricing
- Add services to events
- Manage bookings and messages

## Project Status
Currently in the planning and prototyping phase.
